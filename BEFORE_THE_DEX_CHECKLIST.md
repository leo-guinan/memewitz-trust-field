# Before You Buy the DEX — launch checklist

Use this before treating a token launch, migration, or DEX payment as a trust event.

This is a research checklist, not financial advice. A checked box does not make a token safe, liquid, or profitable. It means one question has a receipt.

## Critical first pass

- [ ] I can name the exact chain, mint, creator, and official project account.
- [ ] I know whether the token is pre-migration, migrated, or inactive.
- [ ] I can distinguish organic holders from wallets controlled by the creator, bot, insiders, or linked clusters.
- [ ] I know what the bot does, what it does not do, and where it has failed.
- [ ] I have checked liquidity, holder distribution, and trading activity independently.
- [ ] I have checked every lock, burn, and supply claim against a source.
- [ ] I understand what paying the DEX changes mechanically—and what it does not change.
- [ ] I know who receives community contributions and what happens if the target is not reached.
- [ ] I have a plan for migration failure, developer disappearance, bot failure, or token death.
- [ ] I know what evidence would make me change my mind.

## The better first milestone

- [ ] The community has a shared artifact that is not a payment.
- [ ] Early believers can be identified without exposing private wallet data.
- [ ] A Print.World collection has fixed supply, eligibility, metadata, transferability, and failure rules.
- [ ] The NFT is not represented as guaranteed liquidity or guaranteed token value.
- [ ] A holder can transfer or sell the NFT independently if a market exists.
- [ ] The collection still has identity value if the token fails.
- [ ] The creator has published a claim ledger and correction policy.
- [ ] The first community mission produces evidence, not just posts or volume.

## Stop conditions

- [ ] Pause if anyone asks for seed phrases, private keys, or signatures through an unverified link.
- [ ] Pause if the only proposed proof is price movement.
- [ ] Pause if the community is pressured to contribute immediately.
- [ ] Pause if a creator claim cannot be independently checked.
- [ ] Pause if the NFT is being sold as a guaranteed exit route.
